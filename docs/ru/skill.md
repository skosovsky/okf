# Установить навык OKF для агента {#page-top}

Навык `open-knowledge-format` даёт агенту инструкции: как читать и создавать заметки, указывать источники и проверять результат. Он пригодится, когда вы хотите поручить агенту работу с набором знаний. Инструменты MCP подключаются отдельно.

## Подготовка {#prerequisites}

Нужны исходный клон OKF, Go 1.25.5 или новее и авторизованный Codex CLI с поддержкой навыков проекта. Пример устанавливает навык только в отдельный учебный каталог, не меняя ваш рабочий проект.

## Установка в проект {#install}

```sh
codex --version
repo_root=$(pwd)
skill_demo_dir=$(mktemp -d)
go build -o "$skill_demo_dir/okf" ./cmd/okf
mkdir -p "$skill_demo_dir/.agents/skills"
cp -R skills/open-knowledge-format "$skill_demo_dir/.agents/skills/open-knowledge-format"
cp -R examples/project-knowledge/ru "$skill_demo_dir/knowledge"
export PATH="$skill_demo_dir:$PATH"
cd "$skill_demo_dir"
codex
```

Выполняйте команды из корня клона; переменная `repo_root` хранит путь для возврата. Копируйте весь каталог навыка: его ссылки ведут на вложенные инструкции и спецификацию. В Codex откройте список навыков через `/skills` и найдите `open-knowledge-format`. Если его нет, начните новую сессию из `skill_demo_dir` и проверьте `.agents/skills/open-knowledge-format/SKILL.md`.

## Первое применение {#use}

Явно вызовите навык в запросе:

> $open-knowledge-format Прочитай набор knowledge. Когда нужно подключить оператора при неудачной доставке? Открой retry-policy.md и source-material.md, приведи ссылки на оба документа. Выполни okf validate --path knowledge --spec 0.2 --strict --check-links --check-orphans --max-warnings=0 и объясни результат. Не изменяй файлы.

Ожидайте чтение инструкции навыка, двух документов и реальное выполнение команды. Ответ должен говорить о 24 часах и показывать источник; отчёт проверки должен быть без ошибок и предупреждений. Список установленного навыка подтверждает обнаружение, а журнал чтения и команды — его фактическое применение.

После изменения срока до 48 часов в обоих документах повторите запрос. Агент должен прочитать текущее состояние, а не воспроизвести прежний ответ.

## Другие задачи {#tasks}

- Создать заметку: дайте агенту конкретные исходные материалы и попросите связать утверждения с источниками.
- Перейти с 0.1 на 0.2: сначала запросите план по [руководству миграции]({{ '/ru/migration/' | relative_url }}).
- Поддерживать знания после изменений: используйте отдельный навык `okf-maintain` и [руководство обновления]({{ '/ru/knowledge-upkeep/' | relative_url }}).
- Восстановить знания из Git: отдельный навык `okf-backfill` ведёт от истории и материалов к проверенному плану; применяйте изменения после его просмотра.

## Если не получилось {#troubleshooting}

Если `okf` не найден, проверьте `PATH` в оболочке запуска Codex. Если агент только описал проверку, попросите выполнить команду и показать вывод. Если нужна работа через MCP, следуйте [отдельной инструкции]({{ '/ru/getting-started-mcp/' | relative_url }}).

Инструкции навыка и формальная спецификация доступны в [библиотеке документов]({{ '/ru/readings/skills/open-knowledge-format/SKILL/' | relative_url }}). Версия пакета навыка, версия программы и `okf_version` документа независимы. Сведения о производителях и проверках записывайте только по реальным действиям; вложенные computation-ресурсы исполняются только в отдельно выбранной и разрешённой среде.

[Официальная инструкция Codex по навыкам — английский оригинал](https://learn.chatgpt.com/docs/build-skills). Каталоги проекта загружаются из `.agents/skills` от текущей папки до корня репозитория.
