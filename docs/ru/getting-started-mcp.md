# Дать агенту найти правило через MCP {#page-top}

MCP предоставляет агенту инструменты для чтения знаний. Здесь агент должен найти правило доставки, прочитать заметку и её источник, затем ответить со ссылками. Подготовьте Codex CLI с авторизованной учётной записью и исходный репозиторий из первого запуска.

## Подготовить отдельную сессию {#connect}

Выполняйте из корня клона. Используем отдельную копию учебного набора и настройки только для этой сессии; `-c` не сохраняет MCP-сервер в глобальную конфигурацию.

```sh
codex --version
mcp_demo_dir=$(mktemp -d)
go build -o "$mcp_demo_dir/okf-mcp" ./cmd/okf-mcp
cp -R examples/project-knowledge/ru "$mcp_demo_dir/knowledge"
knowledge_root="$mcp_demo_dir/knowledge"
printf '%s\n' "$knowledge_root"
cd "$mcp_demo_dir"
codex -c "mcp_servers.okf.command=\"$mcp_demo_dir/okf-mcp\"" -c 'mcp_servers.okf.args=[]'
```

В клиенте откройте `/mcp`. Сервер `okf` должен быть подключён; в списке инструментов должны присутствовать `search_sections` и `read_concept`. Сервер принимает путь к набору в каждом вызове, через абсолютный `bundle_path`, а не через аргумент `-root`.

## Задать вопрос {#ask}

Подставьте напечатанный путь вместо `<абсолютный путь>`, затем отправьте:

> Используй MCP-сервер okf с bundle_path `<абсолютный путь>`. Найди правило доставки через search_sections с запросом `доставку оператор`, прочитай retry-policy через read_concept, затем прочитай source-material как источник. Когда нужно подключить оператора? Ответь по предоставленным требованиям, со ссылками на заметку и источник. Покажи фактически выполненные вызовы. Ничего не изменяй.

Ожидаемый результат: агент действительно выполняет вызовы и отвечает о **24 часах**, ссылаясь на `retry-policy` и `source-material`. Сверьте ответ с документами. Если вы используете уже изменённую копию из первого запуска, ожидаемый срок — **48 часов**.

## Проверить отдельные вызовы {#diagnostics}

Если клиент отвечает без инструментов, попросите выполнить эти вызовы явно. Путь в JSON должен быть абсолютным:

`search_sections`:

```json
{"bundle_path":"<абсолютный путь>","query":"доставку оператор","limit":5}
```

`read_concept`:

```json
{"bundle_path":"<абсолютный путь>","concept_id":"retry-policy"}
```

```json
{"bundle_path":"<абсолютный путь>","concept_id":"source-material"}
```

Поиск возвращает фрагменты, строки и контрольные суммы. Чтение возвращает текст заметки и сведения об источнике; второй вызов позволяет проверить сам источник. Сохраните версию клиента, настройки без секретов, запрос, вызовы и ответ — это подтверждение подключения для конкретного запуска.

## Если не получилось {#troubleshooting}

- Сервер не запускается: проверьте абсолютный путь к собранному `okf-mcp` и сообщения клиента.
- Набор не найден: используйте абсолютный путь, напечатанный перед запуском клиента.
- Поиск пуст: проверьте язык учебной папки и слова запроса.
- Ответ без вызовов: попросите выполнить диагностические вызовы; одна запись сервера в настройках не подтверждает подключение.

[Навык агента]({{ '/ru/skill/' | relative_url }}) устанавливается отдельно. Каталог всех 14 инструментов и их ограничения — в [справочнике]({{ '/ru/reference/' | relative_url }}). Этот запуск проверяет подключение и чтение материалов, а не измеряет качество модели.
