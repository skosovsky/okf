# Ручная проверка навигации по `knowledge/` {#page-top}

**Историческая проверка: 2026-09-26.** Результаты описывают состояние на эту дату. Проверяющий начал с `knowledge/index.md` и прошёл по ссылкам как читатель. Это проверка содержания и навигации; черновые заметки не получили формального подтверждения, а закреплённые URL источников не загружались из сети.

## Вопросы и результаты {#results}

| Вопрос инженера | Путь из индекса | Найденный ответ | Проверенный источник |
| --- | --- | --- | --- |
| Где предлагаемое изменение становится долговечной записью? | `knowledge/index.md` → **Changes and durability** → `knowledge/mutation.md` → `knowledge/store.md` | Типизированный `store.ChangeSet` проходит предварительный просмотр с ревизией и контрольной суммой плана; разрешённое применение идёт через хранилище. MCP требует данные предварительного просмотра. Хранилище обеспечивает долговечный коммит и восстановление. | `store/change.go` задаёт закрытый интерфейс операций; `docs/toolkit.md` на дату проверки описывал пары MCP preview/apply и привязку изменения к ревизии и контрольной сумме. |
| Может ли долговечное файловое хранилище работать на этой платформе? | `knowledge/index.md` → **Changes and durability** → `knowledge/platforms.md` | `store/fs` поддерживает Darwin и Linux при успешных проверках возможностей файловой системы. Windows и другие платформы компилируются, но `Open`/`OpenContext` возвращают `*fs.UnsupportedPlatformError`; доступен `errors.Is` с `fs.ErrUnsupportedPlatform`. | Контракт пакета и тип ошибки в `store/fs/fs.go`; матрица платформ в `docs/release-engineering.md`. |
| Выбирает ли версия пакета версию OKF? | `knowledge/index.md` → **Reading and conformance** → `knowledge/versions.md`; также метаданные корневого индекса | Нет. Набор объявляет `okf_version: "0.2"`. Контракт документа независим от версии плагина и Go-модуля; отсутствие объявления даёт 0.2, явный поддерживаемый режим проверяет версию, а несовпадение вызывает ошибку. | Оси версий и правила разрешения в `docs/toolkit.md`; типы и реализация в `bundle/version.go`. |

Все три пути дали ответ без поиска и тестовых утверждений. Осталось замечание: `knowledge/versions.md` объясняет различие, но не указывает конкретные версии пакетов; связанное руководство тогда приводило `0.2.0` для плагина, `v0.2.1` для Go-модуля и `0.2` для документа. Это иллюстрация независимых версий, а не сведения о последнем релизе.

Английские заголовки в таблице сохранены как точные названия исходных заметок. Для текущей работы используйте [руководство по знаниям репозитория]({{ '/ru/knowledge/' | relative_url }}).
