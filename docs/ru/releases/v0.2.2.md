# OKF v0.2.2 {#okf-v022}

Тег [`v0.2.2`](https://github.com/skosovsky/okf/releases/tag/v0.2.2) создан 2026-09-17. Эта страница описывает тот выпуск, а не последующие изменения текущей рабочей копии. Существующие теги нельзя перемещать или создавать заново.

## Включённые работы {#included-work}

Выпуск реализует программу task09–21:

- Зафиксированный контракт OKF v0.2, набор примеров для проверки соответствия, типизированную модель набора знаний, проверку с учётом версии и профиль проекции графа.
- Структурные изменения YAML без потери исходного оформления, закрытый набор семантических операций v0.2 и транзакционную миграцию из v0.1, связанную с подтверждением плана.
- Проверки совместимости хранилища, надёжное восстановление `store/fs` и декодирование содержимого журнала с ограничением размера.
- Команды CLI с учётом версии, девять MCP-инструментов с проверкой схем, согласованные руководства EN/RU, тестовые данные, примеры и упаковку плагина.

Исторические регрессионные наборы тестов были сгруппированы по поведению без сокращения состава из 401 функции верхнего уровня `Test*`/`Fuzz*`. Отслеживаемые материалы разработки содержат исходные хеши и соответствие между старым и новым расположением тестов.

## Усиление миграции {#migration-hardening}

- При неудачном открытии рабочего хранилища больше не остаётся интерфейс с типизированным nil для отложенной очистки; поэтому `okf migrate --write` возвращает рабочую ошибку вместо паники.
- Darwin обрабатывает фиксированные системные псевдонимы `/var` и `/tmp` как их целевые пути `/private/var` и `/private/tmp` перед обходом с доступом через файловые дескрипторы. Произвольные компоненты пути, являющиеся символьными ссылками, по-прежнему отклоняются.
- Рабочий MCP-сценарий `target-noop`, предварительный просмотр CLI и CLI `--write` имеют разные контракты адаптеров надёжного хранения, описанные в английских и русских материалах.

## Совместимость и ограничения {#compatibility-limitations}

- Формат документа остаётся `okf_version: "0.2"`; версии выпуска репозитория, пакета плагина и спецификации документа независимы.
- Публичные Go API, ChangeSet v1 и CommitReceipt v1 сохраняют совместимость.
- Исполнение, среда аттестации, ABI аттестатора, изоляция, получение ресурсов по сети и выдуманная оценка доверия не входят в объём работ.
- Аннотированный тег `v0.2.2` указывает на коммит [`8e5ef56`](https://github.com/skosovsky/okf/commit/8e5ef566b87004afe45e9e57cda9ff0ed0705b8d).
