# OKF v0.2.0 {#okf-v020}

`v0.2.0` — существующий аннотированный тег, содержащий основу транзакционных изменений из коммита [`43f7214`](https://github.com/skosovsky/okf/commit/43f7214) и реализацию изменений без потери исходного оформления на основе парсера из коммита [`bb9c169`](https://github.com/skosovsky/okf/commit/bb9c169).

## Дополнения публичного API {#api-additions}

- Неизменяемые снимки и ревизии с указанием алгоритма вычисления.
- Версионированные операции `store.ChangeSet` и предусловия.
- Предварительный просмотр подготовленных изменений и проверка.
- Оптимистическая фиксация по принципу compare-and-swap и доступные для изучения конфликты.
- Ограниченное хранение квитанций идемпотентности.
- Надёжная фиксация с журналом и восстановление в `store/fs`.
- Планирование изменений `EnsureRelation`, `MoveConcept` и `RenameFragment` на основе парсера без потери исходного оформления.

Существующие контракты разбора набора знаний, проверки, графа, CLI и обмена MCP сохраняют совместимость исходного кода. Выпуск не добавляет профили методологий, состояния рабочих процессов или типы предметной области конкретного бизнеса.

## Платформы и границы изоляции {#platform-isolation}

Реализация надёжного хранения `store/fs` в теге предназначена для Darwin и Linux. Блокировки рекомендательные: обычные редакторы с ними не согласуются, а обычный читатель может увидеть промежуточное состояние переименования нескольких файлов во время публикации. Восстановление обеспечивает завершение транзакции, но не распределённую изоляцию. Последующие работы по подготовке выпусков v0.2.x обеспечивают сборку на неподдерживаемых платформах и типизированную ошибку во время выполнения вместо отсутствующих символов.
