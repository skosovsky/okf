# Работа со знаниями репозитория (для копирования в CLAUDE.md)
{: #section-1 }

Перед изменением кода прочитайте `knowledge/index.md` и только заметки, относящиеся к задаче. Сверьте их утверждения со связанным исходным контрактом или текущим кодом; заметка помогает найти нужные сведения.

В начале рабочего сеанса зафиксируйте исходное состояние с помощью `okf-upkeep`, если репозиторий его использует. После изменения кода проверьте затронутые заметки. Обновите заметки и `knowledge/log.md`, если утверждения изменились. Иначе запишите конкретную причину, почему текущие изменения кода не влияют на набор, и свяжите её с текущим отпечатком изменений upkeep. Изменённый журнал или успешная валидация не доказывают истинность заметки. Не выводите `verified` или метаданные актуальности из истории Git.

После редактирования набора используйте принятую в репозитории команду проверки Go. Миграция — отдельная явно заданная операция.
