# Предварительная пробная проверка: результатов модели нет
{: #section-1}

Эта пробная проверка из двух испытаний использовала один случай на основе репозитория (`repo-default-okf-version`), модель `gpt-6-luna` с низким уровнем рассуждений, предел общего времени 120 секунд, предел 20,000 наблюдаемых токенов и не более двух вызовов модели. Запуск выполнен в рабочем дереве с незакоммиченными изменениями до коммита исправленной реализации. Он явно непригоден для приёмки задачи 012.

Экспериментальная группа трижды вызывала настоящий Go CLI (`validate`, затем `parse` для обеих заметок). Исходная запись экспериментальной группы фиксирует три вызова инструментов. Обе попытки обращения к модели завершились до генерации ответа: Codex CLI не смог записать свою базу состояния при файловых ограничениях среды, затем не смог инициализировать клиент app-server. Поэтому фактических наблюдений, данных о токенах или оценок точности нет.

`plan.original.json` и `rows.original.jsonl` — точные файлы, записанные версией среды оценки этого пробного запуска. `plan.json` и `rows.jsonl` добавляют поля, введённые после него (`spec_sha256`, `adapter_sha256`, режим, метку предварительного запуска, нулевое/неизвестное время испытания, ноль наблюдаемых прямых вызовов CLI и пустые копии вывода инструментов), чтобы текущий анализатор мог пересчитать результат. Добавленные значения внесены **после наблюдений** и не могут считаться заранее зарегистрированными свидетельствами. `report.json` — получившийся некорректный отчёт. `corpus.json` — зафиксированные входные данные одного случая.

Повторная попытка с повышенными разрешениями отклонена автоматической проверкой разрешений, поскольку внешняя модель могла получить содержимое репозитория и доступ к оболочке, а также записывать состояние вне рабочего каталога. Нельзя использовать другой домашний каталог или другого провайдера для обхода отказа. Для живого пилота необходимо явное разрешение пользователя на запуск внешней модели, затем чистый исправленный коммит и новый план.
