# Проекция графа `skosovsky/okf-v0.2-instant` {#doc-section-001}

Этот дополнительный профиль использует те же правила идентификации узлов, словарь, упорядочивание, устранение дубликатов и соответствие JSON-LD/N-Triples, что и [`v0.2`]({{ '/ru/readings/graph/contracts/v0.2/' | relative_url }}). Его машиночитаемый контракт — [`v0.2-instant.json`](https://github.com/skosovsky/okf/blob/61e75e9aa9a8719dfb480bf1f5226553b3a21d70/graph/contracts/v0.2-instant.json).

Выбранная временная ревизия OKF 0.2 — `instant-0b87c52`. Предикаты `staleAfter`, `stalenessAsOf`, `lastModified`, `usageFrom` и `usageTo` содержат литералы `xsd:dateTime` только после того, как парсер набора проверил временную метку со смещением часового пояса. Исходный профиль `skosovsky/okf-v0.2` по-прежнему использует для этих предикатов `xsd:date` и сохраняет зафиксированные байты.

Явное значение `Options.AsOf` задаёт опорный момент времени. Без него граф не содержит `stalenessAsOf` и `stale`; при отсутствии или некорректности `stale_after` устаревание также не вычисляется. Сравниваются точные моменты, включая дробные наносекунды, а граничный момент включается.
