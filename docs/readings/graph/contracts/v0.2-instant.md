# `skosovsky/okf-v0.2-instant` graph projection {#doc-section-001}

This additive profile uses the same node identity, vocabulary, ordering,
deduplication and JSON-LD/N-Triples parity as
[`v0.2`]({{ '/readings/graph/contracts/v0.2/' | relative_url }}). Its machine-readable contract is
[`v0.2-instant.json`](https://github.com/skosovsky/okf/blob/61e75e9aa9a8719dfb480bf1f5226553b3a21d70/graph/contracts/v0.2-instant.json).

The selected OKF 0.2 temporal revision is `instant-0b87c52`. The predicates
`staleAfter`, `stalenessAsOf`, `lastModified`, `usageFrom`, and `usageTo`
carry `xsd:dateTime` literals only after the bundle parser has validated an
offset-bearing timestamp. The original `skosovsky/okf-v0.2` profile still
uses `xsd:date` for these predicates and retains its frozen bytes.

An explicit `Options.AsOf` supplies the reference instant. Without it the
graph omits `stalenessAsOf` and `stale`; malformed or absent `stale_after`
also leaves staleness unevaluated. Comparisons use exact instants, including
fractional nanoseconds, and the boundary is inclusive.
