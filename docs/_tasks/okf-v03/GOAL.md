# Полная поддержка Open Knowledge Format 0.3

## Текст goal для исполнителя

Реализуй OKF 0.3 в skosovsky/okf от чтения чужого bundle до безопасной записи и повторного чтения. Начни с закреплённой спецификации и версионного контракта. Проведи одни и те же документы через Go API, CLI, MCP, Action, поиск, граф, viewer и рабочие процессы skills. Человек должен суметь открыть старый проект, увидеть последствия перехода, применить миграцию явно и проверить результат. Сохрани контракты 0.1 и обеих исторических редакций 0.2. Обнови обе локали сайта, примеры, демо и описания поставки. Оставь на пользовательском маршруте только действия, ожидаемый результат и ссылку на подробности. Закрой каждую карточку ниже воспроизводимым доказательством. Уровень поддержки в публичных материалах должен совпадать с пройденной приёмкой.

## Что считать готовым

Для каждого применимого MUST, MUST NOT и SHOULD из §§3–12 есть строка матрицы, владелец и проверяемое поведение; отклонение от SHOULD объяснено. Каждый режим записи прошёл round-trip на данных с чужими расширениями. Старые версии проверены собственными ожиданиями. Одни и те же входы дали согласованные результаты во всех применимых интерфейсах. Пройдены публичные маршруты на обоих языках. Итоговый отчёт привязан к коммиту и содержит команды, версии, результаты, известные ограничения и ссылки на доказательства. Выпуск тега и публикация релиза — отдельные действия владельца.
