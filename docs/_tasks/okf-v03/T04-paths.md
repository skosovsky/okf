# T04. Разрешать ссылки и показывать замену концепта

bundle/path_value.go уже различает корень и каталог документа; его перечень полей заканчивается attester.resource. В graph/projection.go уже есть проекции ресурсов, источников, атрибуции и собственных relations.

## Результат

- Единый resolver §§5.4, 6 для Markdown, resource, sources[].resource, computation, executor.resource, attester.resource, superseded_by; отдельно разрешать путь к лицензии из root index. Соблюдать URI scheme, percent-encoding, регистр, fragment и границу снимка bundle. Scope descriptor оставить непрозрачным.
- Для старого или unversioned bundle сначала файл-сосед, затем допустимый fallback полей от корня. Строить направленные рёбра только к концептам; ссылки на asset, внешний URI и директорию остаются наблюдаемыми. Отделить иерархию каталогов и расширения typed relations от стандартного графа.
- superseded_by имеет смысл на deprecated. Для запроса current следовать замене; прямой запрос исторического ID возвращает исходный документ с указателем. Зафиксировать поведение при цепи, цикле, отсутствующей цели, неизвестном status и ограничении ответа.

## Приёмка

- [ ] Тест с двумя policy.md выбирает соседа; при единственном корневом файле fallback разрешён только для нужных версий и полей. Сломанная ссылка не нарушает base conformance.
- [ ] Проверены пробел через %20, различный регистр, fragment, symlink наружу, ../ наружу, reference-style, картинка, кодовый блок и scope. Запрос не читает за пределами root.
- [ ] Для цепочки old → intermediate → new совпадают current-результаты графа и поиска; broken/cycle завершаются ограниченно с объяснением. Typed relations и иерархия остаются различимыми в экспорте.
