# T08. Публичные Go, CLI и MCP контракты

На базе `0d01adc` справочник перечислял 15 команд основного CLI и 14 MCP-инструментов. В internal/mcpserver/contracts лежат входные и выходные JSON Schema. Сначала обновить контракт и реестр discovery, затем адаптеры и примеры. Сохранить BYOT и сырой доступ к документу. У версионно-зависимых Go accessor без контекста версии описать историческое значение и дать версионный путь чтения через bundle.

| Поверхность | Что принять |
|---|---|
| CLI version, help, info, parse | Поддерживаемая версия, effective version, root metadata, raw/effective значения, причины trust и freshness согласованы между text и JSON. |
| CLI validate, graph, view, search | Одинаковые ID, разрешённые пути, состояние замены, время сравнения и диагностики. |
| CLI init, setup, fmt, index, migrate-prepare, migrate, temporal-upgrade | Новые записи 0.3, сохранение чужих полей; версия и границы старых операций видны в help и ошибках. |
| MCP list_concepts, read_concept, search_concepts, search_sections | Новые проекции в ответах; бюджет, порядок, пагинация и прямое историческое чтение предсказуемы. |
| MCP get_semantic_graph, get_neighbors, validate_bundle | В выдаче различимы Markdown-связь, path field, replacement и расширения; диагностики совпадают с CLI на одном снимке. |
| MCP write_concept, preview_concept_patch, apply_concept_patch | Проверить авторизацию, версию, raw/effective, путь ошибки и receipt; новые поля управляемы через обычный публичный путь записи. |
| MCP preview_v02_migration, apply_v02_migration, preview_temporal_upgrade, apply_temporal_upgrade | Имена и старые доказательства сохраняют прежнее значение. Для перехода 0.2 → 0.3 добавить явную пару preview/apply с отдельными схемами. |

**Предложение по инструментам.** В существующем info/read_concept дать объяснение tier с датой последней содержательной правки и учтёнными/историческими событиями. В search предоставить режим current и указать исходный и конечный ID после замены. Миграционная пара решает новую операцию записи; отдельный MCP-сервер и новый валидатор для этого не нужны.

**Приёмка.** Запустить реальный CLI и stdio MCP, получить tools/list, вызвать каждую применимую операцию через tools/call. Схемы, discovery, описания, JSON/text, отмена, лимит выдачи и ошибки проверены. Даты подаются фиксированно. В реестре интерфейсов каждому инструменту соответствует тест или обоснование его версионной нейтральности.
