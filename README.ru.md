# okf

Знания проекта рядом с кодом — для команды и AI-агентов.

Запишите правило в Markdown, укажите источник и дайте агенту найти ответ. Например: после 24 часов неудачной доставки задания нужен оператор. Когда требование изменится, пересмотрите связанную заметку вместе с кодом.

[Открыть учебный пример](https://skosovsky.github.io/okf/demo/project-ru.html#retry-policy) · [Попробовать локально](docs/ru/quickstart.md) · [English](README.md)

## Когда использовать

- Найти ограничение перед изменением сервиса и открыть его источник.
- Объяснить архитектурное решение вместе с материалами, на которых оно основано.
- Пересмотреть связанные знания после изменения требований или кода.

## Как устроено

Набор знаний — папка Markdown-файлов с YAML-метаданными и корневым `index.md`. Файлы можно редактировать, хранить в Git и обсуждать в PR. OKF добавляет согласованные метаданные, ссылки на источники, проверку структуры, поиск и инструменты для агентов.

Open Knowledge Format — спецификация документа. Этот репозиторий — реализация на Go: библиотеки, CLI `okf`, сервер `okf-mcp`, навыки и автономный HTML-просмотрщик. Текущий контракт документа — 0.2; чтение 0.1 и явная миграция поддерживаются. Версия релиза программы не выбирает версию документа.

## Установка и первый результат

Нужны Git и Go **1.25.5 или новее** для запуска из исходников. Чтобы установить команды:

```sh
go install github.com/skosovsky/okf/cmd/okf@latest
go install github.com/skosovsky/okf/cmd/okf-mcp@latest
okf version
```

Если команды не найдены, добавьте каталог `go env GOPATH` с подкаталогом `bin` в `PATH`. Для воспроизводимого знакомства [первый запуск](docs/ru/quickstart.md) собирает программу из клона и копирует учебный пример во временную папку. Затем выполните:

```sh
okf search examples/project-knowledge/ru --query "доставку оператор" --limit 5
```

Ожидайте фрагменты о 24 часах и операторе. Откройте `retry-policy.md`, затем `source-material.md`; полный сценарий показывает также ручное обновление срока до 48 часов.

## Что означает проверка

Валидатор проверяет структуру и ссылки. Утверждения сверяйте с источниками. `sources` указывает материал, `generated` — известного создателя, `verified` — реальную проверку. Эти сведения не появляются автоматически после успешной валидации. Вложенные вычисления требуют отдельно выбранной и разрешённой среды.
