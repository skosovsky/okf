# 017 — Понятная документация EN/RU и локализация просмотрщика

Статус: реализация. Базовая ревизия: 61e75e9aa9a8719dfb480bf1f5226553b3a21d70.

Исполняется утверждённый пользователем план от 2026-10-04. Полный объём закреплён до редактуры в docs/_data/documentation.yml и evidence/017/baseline-registry.json. Все пользовательские документы, включая контракты, ADR и исторические материалы, получают полные EN/RU версии. Нормативные оригиналы и исполняемые skills сохраняются; переводятся их издания для чтения. Зафиксированные данные, журналы, fixtures и knowledge/ не переводятся.

Основной сценарий: сохранить правило проекта с источником → найти ответ → проверить источник → обновить знания при изменении требования. Учебный пример: оператор после 24 часов неудачной доставки.

Публичный контракт: okf view --lang en|ru (default en), viewer.Options.Language, RenderWithOptions и совместимый Render. Переключатель языка внутри автономного HTML сохраняет заметку и фильтры. После reload — язык экспорта. Неизвестные языки отвергаются до публикации файла.
