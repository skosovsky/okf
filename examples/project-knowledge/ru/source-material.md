# Учебные требования к доставке

Это вымышленные требования для знакомства с OKF.

Повторяйте неудачную доставку задания в течение 48 часов. Если доставка всё ещё не удалась, передайте задание оператору. Оператор проверяет причину ошибки перед следующей попыткой.

Во второй редакции срок увеличен с 24 часов.
